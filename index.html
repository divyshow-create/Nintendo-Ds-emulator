🎮 DS Touch

Interfaccia Nintendo DS con controlli virtuali per touch
Scegli un file ROM che possiedi legalmente. L'interfaccia è pronta; il motore di emulazione viene caricato dal web.
Questa versione usa un motore online: non funziona completamente offline e richiede Internet per scaricare il core. La ROM scelta viene letta dal browser e non viene caricata su un tuo server.
Schermo superiore DS
Schermo inferiore DS / touch

Suggerimento: tieni premuto un pulsante virtuale per continuare a premere il tasto. Tocca lo schermo inferiore del gioco per usare lo stilo quando il core lo supporta.

Pubblicazione: carica i file su GitHub e abilita GitHub Pages. Per una vera versione offline, il core JavaScript/WebAssembly e tutti i suoi file devono essere scaricati e salvati nel repository; GitHub Pages da solo non rende offline il sito.
